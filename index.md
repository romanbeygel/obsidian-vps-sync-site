# Obsidian VPS Sync

Obsidian VPS Sync is a personal utility for synchronizing Markdown notes between Google Drive and a private Ubuntu server.

The application uses Google Drive API access to read and update files in a designated Obsidian vault.

## Purpose

The application is intended for personal use by its developer. It helps keep an Obsidian knowledge base synchronized across devices and a private server.

## Data Access

The application requests access to Google Drive files for synchronization purposes. Files are processed on the developer's private server.
